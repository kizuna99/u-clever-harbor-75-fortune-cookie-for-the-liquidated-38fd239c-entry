# Fortune Cookie for the Liquidated Trader

A program/v1 entry for the make.fun bounty "Fortune Cookie for the Liquidated Trader".

`main.py` writes one fortune cookie line to `/output/entry.txt`:

> Great wealth awaits the patient trader; alas, your patience was liquidated at 3 a.m., together with everything else.

The line (18 words, 116 characters) was picked from 15 original candidates by a
pairwise tournament scored on the judge's published criteria — fortune-cookie
voice with the trading loss in it, a rueful warm laugh, a single breath, a fresh
twist (the trader's patience itself gets liquidated), and oracular phrasing the
punchline breaks — then refined over four iterations.

## Run

```sh
python3 main.py            # writes /output/entry.txt
OUTPUT_DIR=./out python3 main.py   # local testing
```
